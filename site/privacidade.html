Política de privacidade

Atualizada em 11 de outubro de 2026.

O Clipador é um app de computador de uso pessoal do Felipe Salviano. Ele roda só no computador do dono e publica só nas contas dele. Não existe servidor do Clipador: nenhum dado das contas conectadas é enviado para o desenvolvedor ou para terceiros, a não ser os envios descritos abaixo, que o próprio usuário pede.

Dados que o app acessa

  • YouTube (Google): permissões youtube.upload, para enviar e agendar os vídeos que o usuário aprovou, e youtube.readonly, para ler o nome do canal e as visualizações dos vídeos enviados pelo app.
  • TikTok: permissões user.info.basic (nome da conta) e video.upload (enviar o vídeo como rascunho).
  • Instagram (Meta): permissões para publicar Reels na conta profissional ligada à Página do usuário e ler as visualizações desses Reels.

Como os dados são usados

  • Publicar ou agendar os vídeos que o usuário revisou e confirmou no app.
  • Guardar as visualizações de cada vídeo publicado pelo app, para sugerir os melhores horários de postagem e melhorar a escolha dos próximos cortes.

Os dados não são vendidos, não são usados para anúncios e não são usados para treinar modelos de IA.

Onde ficam guardados

Tudo fica no computador do usuário, na pasta de dados do app (%APPDATA%\Clipador). Os tokens de acesso das redes ficam criptografados pelo Windows. Os vídeos e as gravações também ficam só no computador, até serem enviados para a rede escolhida.

Serviços de terceiros

  • A transcrição das lives é feita no próprio computador.
  • Se o usuário escolher o provedor OpenAI no app, o texto transcrito dos trechos é enviado à API da OpenAI para gerar notas, ganchos, legendas e hashtags. Junto vai só um resumo da média de visualizações por tipo de momento (por exemplo, "risada: média de 2 mil views"), calculado a partir das estatísticas das contas, para a IA priorizar o que tem funcionado. Não são enviados tokens, dados de identificação das contas, comentários nem dados de outras pessoas.
  • Com o provedor Local, nada disso sai do computador.

Google e YouTube

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O Clipador usa os Serviços de API do YouTube. Ao conectar o YouTube, o usuário concorda com os Termos de Serviço do YouTube, e o tratamento dos dados pelo Google segue a Política de Privacidade do Google.

Como remover o acesso e apagar os dados

  • Google/YouTube: myaccount.google.com/permissions › Clipador › Remover acesso. Também dá para revogar pela página de segurança do Google.
  • TikTok: no app do TikTok, Configurações e privacidade › Segurança › Gerenciar permissões de apps.
  • Instagram/Facebook: Configurações › Integrações comerciais (ou Apps e sites) › remover o app.
  • Para apagar tudo que o Clipador guardou, basta apagar a pasta %APPDATA%\Clipador.
